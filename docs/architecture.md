# 本体と展示の実行範囲

## Go版の本体

[cmd/server](../cmd/server)が共通の入口を持ち、カテゴリ別のハンドラーを `/api/<kind>/` 配下へ接続します。
データはカテゴリ別SQLiteと要約キャッシュに分けて管理します。
ブラウザは[共通のruntime](../frontend/runtime.js)を介して、カテゴリごとの画面を読み込みます。

AI要約の事前処理は[cmd/warm-all](../cmd/warm-all)にあり、原文の入力、節の完了状態、再試行、過去の完了結果の保全を扱います。
今回の公開では、そのコードと合成入力のテストを収録しています。
実際のモデルを動かした精度や生成速度を、新たに測定したものではありません。

## Cloudflareの参考ソース

[cloudflare/worker.mjs](../cloudflare/worker.mjs)は公開用スナップショットの配信と外部API処理の参考ソースです。
実環境の設定、生成済みの配信スナップショット、Durable Objectの配備設定は収録していません。
この公開版だけで本番Workerへ配備する手順は提供していません。
API接続先、料金プラン、制限への適合を今回変更または再検証したものではありません。

## 展示用サーバー

[scripts/run_demo.py](../scripts/run_demo.py)は実際の検索UIに、架空の地点と固定応答を渡します。
Goの代替実装や本番配備用のサーバーとして扱うものではありません。
追加のPythonパッケージ、実カタログ、利用者の設定、APIキーを使わず、ブラウザから試せる範囲を提供します。

展示の応答に限り、共通地図のタイル参照先をローカルの合成背景へ置き換え、背景が地図データではないことを表示します。
HTMLには展示用の説明を添え、LAN専用の計測スクリプトを展示の応答から外します。
すべての応答へ同一オリジンに限定するCSPを付け、特集ページの経路は展示用サーバーでは配信しません。
元のHTMLとvisit-logタグ、画面資産はそのまま収録し、本番アプリには変更を反映していません。
この展示サーバーは開発用のローカル検証で、自己ホストや公開ホスティングへの配備は行っていません。

## データと履歴の境界

コミット済みのコードを、運用リポジトリの履歴から切り離して収録しました。
コードに含まれる本番の公開URLや既存特集ページは、その実装の参照として残しています。
カタログDB、外部写真、要約キャッシュ、クラウド資源の設定、モデル、作業中のJSON抽出処理の変更はコピーしていません。

公開用の変更は、既存のUser-Agentにある連絡先URLを、このリポジトリのURLへ更新した3ファイルです。
リクエストや候補処理のロジックは変更していません。
収録元のハッシュ、ファイルのモード、変更理由を[source-manifest.json](source-manifest.json)へ記録しています。

元のデータを前提とするテストのうち、特産物1919件と実在の品目を検査する1ファイルは収録対象から外しました。
ほかのテストは元のコードを維持し、実データがなくても確認できる処理を合成SQLiteで検証します。
本番カタログの正確さや件数を証明するものではありません。
